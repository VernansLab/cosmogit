Cosmogit

Your git history as a living 3D galaxy.

1. Run this inside any git repo:

curl -fsSL https://cosmogit.web.app/get | node

2. Drop the .cosmogit.json file it writes anywhere on this page, or

Needs git and Node. Your history never leaves your machine: the file is read in your browser. Gource custom logs work too.
